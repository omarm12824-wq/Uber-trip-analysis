Uber Trip Analysis Dashboard
Project Overview

This project analyzes over 103,000 Uber trips using Power BI to identify booking trends, customer preferences, peak demand periods, and operational opportunities.

Objectives
Analyze booking patterns
Identify peak demand hours
Discover most popular pickup and drop-off locations
Evaluate vehicle type preferences
Generate business recommendations
Tools Used
Power BI
Power Query
DAX
Excel
Dashboard Pages
1. Overview Analysis

Executive KPIs and booking performance overview.

2. Time Analysis

Analysis of trips by day, hour, and demand trends.

3. Details

Vehicle types, pickup points, drop-off locations, and trip metrics.

4. Findings & Recommendations

Key business insights and recommendations derived from the analysis.

Key Findings
Saturday and Sunday are the highest demand days.
Upper East Side North is the most active pickup area.
Uber X generated 39K bookings.
Peak demand occurs between 3 PM and 5 PM.
Business Recommendations
Increase Uber X fleet availability.
Position drivers around Upper East Side North.
Add surge capacity during weekends.
Increase driver coverage between 3 PM and 5 PM.
